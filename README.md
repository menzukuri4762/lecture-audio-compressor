# 講義音声 AI最適化コンプレッサー (Lecture Audio AI Compressor)

大学の講義録音（90分前後）を、**100MB以内**に確実に収まる高品質なMP3に変換・圧縮するデスクトップツールです。  
Google NotebookLM、Gemini、ChatGPT、OpenAI WhisperなどのAI文字起こし・要約ツールへのアップロードに最適化されています。

---

## 🌟 主な特徴

1. **100MB上限を確実にクリア**
   - 講義の長さ（90分、120分、それ以上でも）に応じてビットレートを自動計算し、100MB未満（デフォルト目標: 95MB）を厳守します。
   - 90分の講義なら、推奨のクリアなモノラル64kbpsで**約40〜43MB**にスリム化されます。
2. **AI文字起こし特化の音響フィルタ**
   - **モノラル化（mono）**: 講義の声の解像度を維持しながらファイル容量を半減。
   - **低周波空調ノイズカット（highpass 80Hz）**: 講義室のエアコンやマイク振動ノイズを除去。
   - **音声会話ノーマライズ（speechnorm）**: 講師の声が小さくなったりマイクから離れたりしても、AIが聞き取りやすい音量に自動均一化。
3. **直感的な操作**
   - ドラッグ＆ドロップ対応のモダンなデスクトップGUI画面。
   - 複数ファイルの一括登録・バッチ変換に対応。
   - ZoomやTeamsなどの講義録画ファイル（MP4 / MKV等）から音声だけを抽出・圧縮することも可能。
4. **一発ドロップバッチ付き**
   - GUIを開かず、ファイルをバッチアイコンに落とすだけで一瞬で変換できる `drop_here.bat` も同梱。

---

## 🚀 使い方

### 方法1: デスクトップGUIで使う（おすすめ）

1. `run.bat` をダブルクリックしてアプリを起動します。
2. 画面の枠内に音声ファイル（`.m4a`, `.mp3`, `.wav`, `.mp4` など）をドラッグ＆ドロップします。
3. 推定サイズ（約40MBなど）を確認し、**「⚡ 100MB以下に変換開始」** をクリックします。
4. 変換が完了すると、元ファイルと同じ場所に `◯◯_compressed.mp3` が生成されます。

### 方法2: アイコンに直接ドラッグ＆ドロップ（最速）

1. 変換したい講義音声ファイルを `drop_here.bat` のアイコンの上にドラッグ＆ドロップします。
2. 自動的に変換が実行され、同じフォルダに 100MB以内の `_compressed.mp3` が出力されます。

### 方法3: コマンドライン（CLI）

```bash
# 基本変換（95MB目標、AI最適化オン）
python cli.py "講義録音.m4a"

# 目標サイズを25MB（Whisper API向け）に変更
python cli.py "講義録音.m4a" -t 25

# 複数ファイルをまとめて変換
python cli.py "第1回.m4a" "第2回.m4a" "第3回.m4a"
```

### 方法4: スマホ単体（iPhone / Android）で使う

1. **[run_mobile.bat](./run_mobile.bat)**（またはGUIアプリの「📱 スマホ版」ボタン）を実行します。
2. 表示されたURL（例: `http://192.168.x.x:8080/`）を、PCと同じWi-Fiに接続したスマホのSafariまたはChromeで開きます。
3. スマホの「ボイスメモ」や録音ファイルを選択し、「⚡ 100MB以下に変換開始」をタップします。
4. **完全端末内処理（通信量ゼロ）**でスマホ内で直接MP3に圧縮され、そのままスマホに保存またはAIアプリ（NotebookLM, ChatGPT, Gemini等）へ直接共有できます！
5. （Safariの「ホーム画面に追加」をしておくと、PCなしでもいつでもホーム画面から1タップで起動できます）

## ⚙️ 圧縮モード設定

- **🎙️ AI最適化モード (推奨)**:
  - 64kbps モノラル ＋ 会話ノーマライズ ＋ 空調ノイズ低減
  - 90分の講義で約42MB。声が最もクリアに残り、AI認識率が向上します。
- **🎯 目標上限フィット**:
  - 指定した上限サイズ（95MB）を余すことなく使い、最高ビットレートで変換します。
- **🪶 超軽量モード (32kbps)**:
  - 90分の講義を約20MB程度まで極小化します。通信環境が悪い場合や超長時間録音向け。

## 📂 ファイル構成

- [app.py](./app.py): デスクトップGUIアプリケーション本体（「📱 スマホ版」ボタン付き）
- [compressor.py](./compressor.py): 音声解析・自動ビットレート計算・FFmpeg制御コアモジュール
- [cli.py](./cli.py): コマンドライン実行用スクリプト
- [run.bat](./run.bat): ダブルクリック起動用バッチ
- [drop_here.bat](./drop_here.bat): ドラッグ＆ドロップ専用ショートカット
- [run_mobile.bat](./run_mobile.bat): スマホ接続用Webサーバー起動バッチ
- [web/index.html](./web/index.html): スマホ単体で動作するWebクライアント本体
- [web/server.py](./web/server.py): ローカルWi-Fi配信用HTTPサーバー
